# Deal Desk site

The public support and privacy pages for the Deal Desk iPhone game, served by GitHub Pages from `main`.

- `index.html`: the landing page
- `support.html`: the Support URL for the App Store listing
- `privacy.html`: the Privacy Policy URL for the App Store listing

Plain HTML, no scripts, no tracking. Edit a page and push to `main`; GitHub Pages republishes it in a minute or two.

**Keep the privacy page true.** Update it (and its effective date) whenever the app starts collecting, sharing or storing anything new, such as the planned "loan leads" link-out or any change to what the leaderboards post.
